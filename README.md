## Aperçu

Ce portfolio recense mes langages et frameworks (avec un niveau de maîtrise approximatif), ainsi que les projets sur lesquels j'ai travaillé, notamment une application de gestion d'accès pour une salle de sport en PHP/MySQL.

## Stack technique

- HTML5
- CSS3
- JavaScript
- Polices Google Fonts (Space Mono, Syne)
- Icônes Tabler Icons

## Lancer le projet en local

Aucune dépendance ni build nécessaire, c'est un site statique.

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/sankoun692/sankoun692.github.io.git
   ```
2. Ouvrez `index.html` dans votre navigateur (double-clic, ou clic droit → Ouvrir avec).

## Déploiement

Le site est déployé automatiquement via **GitHub Pages** à partir de la branche `main`, dossier racine (`/`). Toute modification poussée sur `index.html` est publiée en quelques minutes sur `sankoun692.github.io`.
